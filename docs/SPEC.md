## 1. ภาพรวม

MinkQuickLax เป็น quick launcher สำหรับ Windows
- link แต่ละตัวเป็น **ไอคอนลอยบนสุดของจอ** วางไว้ตรงไหนก็ได้ กดแล้วเปิดทันที
- รวม link หลายตัวเป็น **กลุ่ม** ได้ ใช้ไอคอนเดี่ยวกับกลุ่มปนกันได้
- ไม่แย่ง focus จาก app ที่ใช้อยู่ ไม่โผล่ใน taskbar หรือ Alt+Tab
- **ฟรีและ open source** (MIT) · มีภาษาไทยและอังกฤษ

### ไม่ทำ (non-goals)
- ไม่ทำเป็น Windows Service และตัว app ไม่รันเป็น admin
- ไม่มีกลุ่มซ้อนในกลุ่ม
- ไม่มีสวิตช์โหมด "เดี่ยว / กลุ่ม / ทั้งคู่"
- ไม่เก็บหรือส่งข้อมูลการใช้งานออกไป (ไม่มี telemetry)
- ไม่รองรับ macOS หรือ Linux

## 4. ฟีเจอร์

ป้าย **[F1] [F2] [F3]** บอกว่าอยู่เฟสไหน

### 4.1 Link

**ประเภท**

| ประเภท | `kind` | ตัวอย่าง | เฟส |
|---|---|---|---|
| โปรแกรม | `app` | `.exe`, `.lnk` | F1 |
| app จาก Start Menu/Store | `shellApp` | ชื่อจาก `shell:AppsFolder` เช่น `Microsoft.WindowsCalculator_8wekyb3d8bbwe!App` | F1 |
| ไฟล์ | `file` | `.pdf`, `.xlsx` | F1 |
| โฟลเดอร์ | `folder` | `D:\งาน` | F1 |
| เว็บ | `url` | `https://…` | F1 |
| คำสั่ง/script | `command` | `.bat`, `.ps1`, คำสั่งพร้อม argument | F2 |
| หน้าตั้งค่า Windows | `msSettings` | `ms-settings:display` | F2 |

**ข้อมูลของ link:** ชื่อ, icon, เป้าหมาย, argument, working directory, เปิดในฐานะผู้ดูแลระบบ (ราย link)

**ช่องทางเพิ่ม link**
- [F1] สแกนหา app ในเครื่อง: รายชื่อจาก `shell:AppsFolder` (เหมือน All apps) และ shortcut บน Desktop · มีช่องค้นหา · กรองได้: ทั้งหมด/โปรแกรม/Store/Desktop · ติ๊กเลือกหลายตัวแล้วเพิ่มทีเดียว · แก้ชื่อได้ก่อนเพิ่ม
- [F1] เพิ่มเอง: เลือกไฟล์, เลือกโฟลเดอร์, ใส่ URL
- [F2] ลากไฟล์, shortcut หรือ URL จาก browser มาวางบนที่ว่างหรือบนกลุ่ม

**icon**
1. [F1] ดึงจาก app ความละเอียด 256px
2. [F1] เลือกไฟล์ PNG หรือ ICO เอง · [F2] SVG
3. [F1] favicon สำหรับ URL ดึงจากเว็บนั้นโดยตรง ไม่ผ่านบริการภายนอก
4. [F1] ตัวอักษรบนพื้นสี เมื่อไม่มี icon (ดูหัวข้อ 5.3)

**วางหลายที่และการลบ**
- link เดียวเป็นไอคอนเดี่ยวได้หลายตัว และอยู่ได้หลายกลุ่ม (กลุ่มละไม่เกิน 1 ครั้ง)
- แก้ชื่อหรือ icon ครั้งเดียว เปลี่ยนทุกที่
- **เอาออกจากจอ:** ลบแค่ของบนจอชิ้นนั้น link ยังอยู่ในรายการ
- **ลบ link:** หายจากทุกที่ ต้องถามยืนยัน และบอกว่าวางอยู่กี่ที่

### 4.2 ไอคอนเดี่ยว [F1]

**โหมดใช้งาน**
- ตำแหน่งล็อกไว้ **คลิกเดียว** เพื่อเปิด (เปลี่ยนเป็นดับเบิลคลิกได้)
- ชี้ค้าง 350ms แล้วชื่อขึ้น หรือตั้งให้แสดงชื่อใต้ไอคอนตลอด
- ตอนไม่ได้ใช้ ความทึบ 70% · เมาส์เข้าใกล้ภายใน 130px จะชัดขึ้นจนเต็ม
- ขยายตามเมาส์ได้สูงสุด 1.16 เท่า (ปิดได้)
- กดแล้วไอคอนเด้งหนึ่งครั้ง
- **Ctrl+ลาก:** ย้ายไอคอนได้ทันทีโดยไม่ต้องเข้าโหมดแก้ไข (ปิดได้)

**เมนูคลิกขวา**
1. เปิด
2. เปิดในฐานะผู้ดูแลระบบ (เฉพาะ `app`, `command`)
3. เปิดตำแหน่งที่เก็บ (เฉพาะ `app`, `file`, `folder`)
4. ─
5. วางเพิ่มบนจอ
6. เพิ่มเข้ากลุ่ม… (เลือกกลุ่มที่มีอยู่ หรือสร้างใหม่)
7. แก้ไข… (เปิดหน้าตั้งค่าที่ link นี้)
8. จัดวางไอคอน (เข้าโหมดแก้ไข)
9. ─
10. เอาออกจากจอ
11. ลบ link… (สีแดง)

### 4.3 กลุ่ม

| แบบ | ตอนปกติ | ตอนใช้ | เฟส |
|---|---|---|---|
| **โฟลเดอร์** (ค่าเริ่มต้น) | ไอคอนเดียว ขนาดเท่าไอคอนเดี่ยว ข้างในเป็นไอคอนย่อ 2×2 ของ 4 ตัวแรก | คลิกแล้วกางเป็นแผง | F1 |
| **แถบ** | ไอคอนเรียงเป็นแถวแนวนอนหรือแนวตั้ง มีชื่อกลุ่ม | กดได้เลย ไม่ต้องกาง | F2 |

- **เปิดโฟลเดอร์:** คลิก (ค่าเริ่มต้น) · [F2] ตั้งให้ชี้แล้วกางได้ รอ 200ms ก่อนกาง
- **ทิศที่กาง:** เลือกให้เองตามพื้นที่ว่างบนจอ เช่นโฟลเดอร์ชิดขอบขวาให้กางไปทางซ้าย
- **แผงหุบเมื่อ:** กด link, กด Esc, คลิกที่อื่น
- **ในแผง:** แสดงไอคอนเป็นตาราง มีชื่อกลุ่มด้านบน ชื่อ link ใต้ไอคอน
- **ค่าตั้งของกลุ่ม:** ชื่อ, แบบ (โฟลเดอร์/แถบ), icon (ไอคอนย่อ 2×2 หรือเลือกเอง), จำนวนคอลัมน์ (ค่าเริ่มต้น 4), แสดงชื่อ link
- **เมนูคลิกขวาที่กลุ่ม:** เปิดทั้งหมด [F3], แก้ไขกลุ่ม…, จัดวางไอคอน, เอาออกจากจอ, ลบกลุ่ม… (link ข้างในไม่ถูกลบ)
- **กลุ่มว่าง:** ยังอยู่บนจอ แสดงเป็นโฟลเดอร์เปล่า

### 4.4 จัดวางและลากวาง

**เข้าโหมดแก้ไข:** เมนูคลิกขวาที่ไอคอน/กลุ่ม หรือเมนูที่ tray → "จัดวางไอคอน"

**โหมดแก้ไข [F1]**
- ไอคอนทุกตัวสั่นเบา ๆ ชื่อไอคอนซ่อน
- วางแล้วชิดกริด 24px หรือชิดแนวไอคอนอื่นเมื่อห่างไม่เกิน 8px มีเส้นประช่วยจัดแนว
- ระหว่างลากมีป้ายบอกพิกัด
- วางทับกันไม่ได้ ถ้าปล่อยทับ ไอคอนจะขยับไปช่องว่างที่ใกล้ที่สุด
- **ลากค้างบนไอคอนเดี่ยวอีกตัว 0.6 วินาที:** ไอคอนเป้าหมายขยายขึ้นเป็นสัญญาณ ปล่อยแล้วสร้างกลุ่มใหม่จากสองตัวนั้น
- **แป้นพิมพ์:** ลูกศรขยับทีละ 24px (Shift+ลูกศร ทีละ 1px) · Delete = เอาออกจากจอ · Ctrl+Z = ย้อนกลับ · Ctrl+Y = ทำซ้ำ
- **แถบเครื่องมือด้านบนจอ:** เพิ่ม · จัดเรียงใหม่ · ยกเลิก (คืนทุกอย่างก่อนเข้าโหมด) · เสร็จ
- [F2] เลือกหลายตัว: ลากเป็นกรอบ หรือ Ctrl+คลิก แล้วลากไปพร้อมกัน

**สิ่งที่ลากได้ในโหมดแก้ไข**

| ลากอะไร | ไปวางที่ไหน | ผลที่ได้ | เฟส |
|---|---|---|---|
| ไอคอนเดี่ยว | ที่ว่างบนจอ | ย้ายตำแหน่ง | F1 |
| ไอคอนเดี่ยว | บนกลุ่ม | ย้ายเข้ากลุ่ม (ไอคอนเดี่ยวนั้นหายไป) | F1 |
| ไอคอนเดี่ยว | ค้างบนไอคอนเดี่ยวอีกตัว 0.6 วินาที | สร้างกลุ่มใหม่ | F1 |
| link ในแผงกลุ่ม | ออกนอกแผง | ย้ายออกจากกลุ่มมาเป็นไอคอนเดี่ยว | F1 |
| link ในแผงกลุ่ม | ตำแหน่งอื่นในแผง | จัดลำดับใหม่ | F1 |
| กลุ่มทั้งกลุ่ม | ที่ว่างบนจอ | ย้ายทั้งกลุ่ม | F1 |
| link จากรายการในหน้าตั้งค่า | บนจอ หรือบนกลุ่ม | วางเพิ่ม | F2 |
| ไฟล์/shortcut/URL จากนอก app | ที่ว่าง หรือบนกลุ่ม | สร้าง link ใหม่ | F2 |

**กติกาตำแหน่ง**
- **ค่าเริ่มต้นวางได้แค่ในพื้นที่ทำงาน** ไม่ทับ taskbar · เปิดให้วางทับได้ในค่าขั้นสูง
- **เก็บตำแหน่ง** เป็นสัดส่วน 0–1 ของพื้นที่ทำงานของจอนั้น วัดที่จุดกลางไอคอน และจำว่าอยู่จอไหน
- **เปลี่ยนความละเอียดหรือ DPI:** คำนวณตำแหน่งใหม่จากสัดส่วน ถ้าหลุดขอบให้ดึงกลับเข้าจอ
- **จอที่เคยวางไว้หายไป:** แสดงบนจอหลักชั่วคราว แต่ไม่แก้ตำแหน่งที่เก็บไว้ เสียบจอกลับแล้วกลับไปที่เดิม ถ้าผู้ใช้ย้ายเองระหว่างนั้นจึงบันทึกตำแหน่งใหม่
- **จัดเรียงใหม่:** เรียงไอคอนและกลุ่มทั้งหมดเป็นตารางชิดมุมขวาบนของจอหลัก เรียงตามลำดับที่เพิ่ม

### 4.5 ซ่อน/แสดง

- [F1] **คลิก icon ที่ tray:** ซ่อน/แสดงทั้งชุด (ปิดได้ ถ้าปิด การคลิกจะเปิดเมนูแทน)
- [F2] **คีย์ลัดซ่อน/แสดงทั้งชุด:** ค่าเริ่มต้นไม่ได้ตั้ง
- [F2] **ซ่อนเองตอนเปิด app เต็มจอ หรือตอน present:** ค่าเริ่มต้นเปิด · ออกจากเต็มจอแล้วแสดงกลับ
- ซ่อน/แสดงพร้อมกันทุกชิ้น ไล่ห่างกันชิ้นละ 14ms
- เปิด app ใหม่จะแสดงเสมอ ไม่จำว่าเคยซ่อนไว้ ผู้ใช้จะได้ไม่คิดว่าไอคอนหาย
- ตอนซ่อนอยู่ tooltip ของ icon ที่ tray ต้องบอกว่า "ซ่อนอยู่"

### 4.6 คีย์ลัดและหน้าค้นหาด่วน [F2]

- **ค่าเริ่มต้น `Win+Alt+Q`** · กดแล้วหน้าค้นหาด่วนเด้งขึ้นตรงตำแหน่งเมาส์
- กดเลข 1–9 เพื่อเปิด หรือพิมพ์ค้นหาได้ทันที · Enter เปิดตัวแรก · Esc ปิด
- ใช้ได้แม้ตอนไอคอนซ่อนอยู่หรือเปิด app เต็มจอ
- **หน้าตั้งคีย์ลัด:** กดคีย์ที่อยากใช้เพื่อบันทึก ถ้าตรงกับตารางด้านล่างให้ขึ้นเตือน · ปิดคีย์ลัดได้
- **ถ้าลงทะเบียนไม่ผ่าน:** แจ้งเตือนที่ tray แล้วเปิดหน้าตั้งคีย์ลัด
- **ข้อจำกัด:** `RegisterHotKey` ตรวจเจอเฉพาะ app ที่จองคีย์ด้วยวิธีเดียวกัน ส่วน app ที่ใช้ keyboard hook ตรวจไม่เจอ

**คีย์ที่ต้องเตือน**

| คีย์ | ชนกับ |
|---|---|
| `Ctrl+Alt+Space` | Claude Desktop |
| `Alt+Space` | PowerToys Run, Copilot, เมนูหน้าต่างของ Windows |
| `Win+Alt+Space` | PowerToys Command Palette |
| `Ctrl+Space` | PowerToys Peek, สลับ IME, autocomplete ใน editor |
| `Ctrl+Shift+…` | CapsLock ที่แมปด้วย AutoHotkey, คีย์ลัดใน app ทั่วไป |
| `Win+Space`, `Alt+Shift+…`, `` ` `` | สลับภาษา |
| `Ctrl+Alt+ตัวอักษร` | AltGr บนคีย์บอร์ดยุโรป |
| `Win+Alt+` B, D, G, H, K, M, R, T, U, P | Windows และ PowerToys |

### 4.9 คู่มือ (HTML)

- **ใช้ได้โดยไม่ต้องมีเน็ต:** ติดมากับตัวติดตั้ง ฟอนต์ รูป CSS และ JS รวมอยู่ในไฟล์ ไม่โหลดจาก CDN
- **เปิดในหน้าต่างของ app (WebView2):** ไปตรงหัวข้อได้ ธีมตรงกับ app · มีปุ่ม "เปิดใน browser" และ "พิมพ์"
  - ถ้าเครื่องไม่มี WebView2 Runtime ให้เปิดใน browser แทน (ไปตรงหัวข้อไม่ได้)
- **สไตล์เดียวกับ app** รองรับธีมสว่างและมืด
- **สารบัญด้านซ้าย:** ไฮไลต์หัวข้อที่กำลังอ่าน · หน้าต่างแคบให้พับเป็นเมนู
- **ค้นหา**
  - กด `/` หรือ `Ctrl+K` · ผลขึ้นทันทีระหว่างพิมพ์ พร้อมข้อความรอบคำที่เจอ · ↑↓ เลือก · Enter ไปที่หัวข้อแล้วไฮไลต์คำ
  - หาแบบข้อความย่อย (substring) ไม่สนตัวพิมพ์เล็ก/ใหญ่ · ไม่ใช้ library ที่ตัดคำด้วยช่องว่าง เพราะใช้กับภาษาไทยไม่ได้
  - ใช้ `Intl.Segmenter('th')` ไว้ไฮไลต์และจัดอันดับผล
  - แต่ละหัวข้อมีคำค้นเพิ่มทั้งไทยและอังกฤษ เช่น "hotkey" เจอหัวข้อ "คีย์ลัด"
- **สองภาษา:** เปิดตามภาษาของ app มีปุ่มสลับภาษา · ทั้งสองภาษาใช้ id หัวข้อเดียวกัน (ภาษาอังกฤษ เช่น `settings-idle-opacity`) · สลับภาษาแล้วยังอยู่หัวข้อเดิม
  - [F1] เนื้อหาภาษาไทย · [F2] เนื้อหาภาษาอังกฤษ ระหว่างนี้หัวข้อที่ยังไม่แปลแสดงภาษาไทยพร้อมป้ายบอก
- **ทางเปิด:** เมนูที่ tray, หน้าเกี่ยวกับ, F1 ในหน้าตั้งค่า, ปุ่ม ⓘ [F2]

**เนื้อหา**
1. เริ่มต้นใช้งาน: ติดตั้ง, หน้าเตือน SmartScreen (วิธีกด More info → Run anyway), เปิดครั้งแรก
2. เพิ่ม link: สแกนหา app, เพิ่มเอง, ลากมาวาง
3. ไอคอนเดี่ยวและกลุ่ม
4. จัดวาง: โหมดแก้ไข, Ctrl+ลาก, ใช้หลายจอ
5. ซ่อน/แสดง, คีย์ลัด, หน้าค้นหาด่วน
6. ค่าตั้งทุกข้อ (1 ข้อ = 1 หัวข้อย่อย มี id ตรงกับปุ่ม ⓘ)
7. แก้ปัญหา: ไอคอนหาย, คีย์ลัดไม่ทำงาน, ไอคอนโดนบัง, ไม่เปิดพร้อม Windows, กู้ค่าตั้ง
8. สำรองข้อมูล, ย้ายเครื่อง, ถอนการติดตั้ง, ลบข้อมูลที่เหลือ
9. ความเป็นส่วนตัว: app ติดต่ออินเทอร์เน็ตแค่ตอนตรวจอัปเดตและดึง favicon
10. คำถามที่พบบ่อย

### 4.10 เปิดพร้อม Windows [F1]

- เปิดตอน **เข้าสู่ระบบ** ไม่ใช่ตอนบูตเครื่อง
- ลงทะเบียนที่ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` ชี้ไปที่ path ของ exe ที่ไม่เปลี่ยนเมื่ออัปเดต และส่ง argument `--startup`
- **ต้องตรงกับ Task Manager:** อ่านสถานะจาก `HKCU\...\Explorer\StartupApproved\Run` ด้วย ถ้าผู้ใช้ปิดใน Task Manager หน้าตั้งค่าต้องแสดงว่าปิด และห้ามเปิดกลับเอง
  - สถานะจริงอ่านจาก registry ทุกครั้ง ไม่เก็บลงไฟล์ค่าตั้ง
- **`--startup`:** แสดงแค่ไอคอนกับ tray ไม่เปิดหน้าต่างใด ๆ
- **ค่าเริ่มต้น:** เปิด ลงทะเบียนตอนเปิด app ครั้งแรก

### 4.11 ติดตั้ง อัปเดต ถอนการติดตั้ง [F1]

- **ตัวติดตั้ง:** `MinkQuickLax-win-Setup.exe` ติดตั้งแบบรายผู้ใช้ ไม่มีหน้าต่าง UAC · รวม .NET ไว้ในตัว
- **Shortcut:** Start Menu เท่านั้น
- **ติดตั้งเสร็จ:** เปิด app ทันที
- **อัปเดต**
  - ตรวจตอนเปิด app และทุก 24 ชั่วโมง
  - เจอเวอร์ชันใหม่ให้ดาวน์โหลดเงียบ ๆ แล้วแจ้งที่ tray: "มีเวอร์ชันใหม่ จะติดตั้งตอนปิด app" พร้อมปุ่ม "รีสตาร์ทตอนนี้"
  - ช่องทาง: ปกติ (stable) และทดลอง (beta)
  - ปิดการตรวจอัตโนมัติได้ ยังกด "ตรวจหาอัปเดต" เองได้
- **ถอนการติดตั้ง**
  - ลบรายการเปิดพร้อม Windows
  - **ไม่ลบค่าตั้งใน `%AppData%\MinkQuickLax\`** เพราะ Velopack แสดงหน้าถามระหว่างถอนไม่ได้ ลงใหม่แล้วได้ค่าเดิมกลับมา
  - ถ้าต้องการลบจริงใช้ปุ่ม "ลบข้อมูลทั้งหมดและออก" ในหมวดข้อมูล หรือทำตามคู่มือ

### 4.12 เปิดครั้งแรก

- **[F1]** ถ้ายังไม่มี link เลย ให้เปิดหน้าสแกนหา app ทันที โดยเพิ่ม link ที่เลือกเป็นไอคอนเดี่ยวเรียงชิดมุมขวาบนของจอหลัก
- **[F2] หน้าต้อนรับ** กดข้ามได้ทุกขั้น
  1. เลือกภาษาและสไตล์
  2. สแกนหา app แล้วติ๊กตัวที่ใช้บ่อย
  3. จัดวางตั้งต้น: ไอคอนเดี่ยวทั้งหมด หรือรวมเป็นกลุ่มเดียว
  4. เปิดพร้อม Windows และตั้งคีย์ลัด
  5. สอนสั้น ๆ: Ctrl+ลาก, คลิกขวา, icon ที่ tray

### 4.13 ภาษา [F1]

- ข้อความทั้งหมดใน app มีภาษาไทยและอังกฤษครบ
- **ค่าเริ่มต้น:** ถ้า Windows เป็นภาษาไทยใช้ไทย นอกนั้นใช้อังกฤษ
- **เปลี่ยนภาษา:** มีผลทันทีโดยไม่ต้องเปิด app ใหม่
- **ชื่อ link:** เป็นข้อมูลของผู้ใช้ ไม่แปล

### 4.14 ฟีเจอร์เฟส 3
- **เปิดหลาย app ทีเดียว (Launch set)**
- **จุดบอกว่า app เปิดอยู่** และกดแล้วสลับไปหน้าต่างเดิมแทนการเปิดซ้ำ (เลือกได้)
- **นำเข้า/ส่งออกค่าตั้ง:** ถ้าไฟล์ที่นำเข้ามี link ประเภท `command` หรือ run as admin ต้องแสดงรายการให้ผู้ใช้ยืนยันก่อน
- **รองรับหลายจอเต็มรูปแบบ:** ย้ายทั้งชุดไปจออื่น และจัดวางแยกชุดตามการต่อจอ

- **รุ่นสำหรับ Windows บน ARM (arm64)**

### 5.5 ทำบน Windows จริง

- **ไอคอนเดี่ยว, แผ่นโฟลเดอร์, ป้ายพิกัด:** หน้าต่างโปร่งใส (layered) วาดกระจกเองโดยไม่เบลอ
- **ชื่อไอคอน, เมนู, แถบเครื่องมือ, แผงกลุ่ม, หน้าสแกน**
  - Windows 11 22H2 ขึ้นไป: ใช้ Acrylic ของระบบ (`DWMWA_SYSTEMBACKDROP_TYPE`) มุมโค้ง 8px ของระบบ แล้ววางพื้นและขอบตามหัวข้อ 5.2 ทับ
  - Windows 10 และ Windows 11 ก่อน 22H2: ไม่เบลอ ใช้พื้นทึบ `a = 0.92`
- **ใช้พื้นทึบ `a = 0.92` เมื่อ:** ผู้ใช้ปิด Transparency effects ของ Windows · เปิดโหมดประหยัดแบต · ปิดการเบลอในหน้าตั้งค่า
- **High contrast:** ใช้สีของระบบทั้งหมด ไม่มีกระจก

## 6. ข้อกำหนดที่ไม่ใช่ฟีเจอร์

| เรื่อง | ข้อกำหนด |
|---|---|
| **focus** | กดไอคอน กลุ่ม หรือเมนู แล้ว focus ต้องยังอยู่ที่ app เดิม · ยกเว้นโหมดแก้ไข หน้าสแกน หน้าตั้งค่า และหน้าค้นหาด่วน ที่ต้องรับการพิมพ์ |

| **บนสุด** | ไอคอนต้องกลับขึ้นบนสุดเมื่อมีหน้าต่างอื่นที่ตั้งบนสุดไว้เหมือนกันมาบัง |
