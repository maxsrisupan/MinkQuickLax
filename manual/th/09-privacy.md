# ความเป็นส่วนตัว {#privacy}

## MinkQuickLax ติดต่ออินเทอร์เน็ตเมื่อไหร่ {#internet}

แค่ 2 กรณี

1. **ตรวจหาอัปเดต:** ถามหน้า Releases ของ MinkQuickLax บน GitHub ว่ามีเวอร์ชันใหม่ไหม และดาวน์โหลดเวอร์ชันใหม่ ปิดการตรวจอัตโนมัติได้ที่[ตรวจหาอัปเดตอัตโนมัติ](#settings-check-updates)
2. **ดึง icon ของเว็บ:** เมื่อเพิ่ม link เว็บ MinkQuickLax ขอ icon (favicon) จากเว็บนั้นโดยตรงครั้งเดียวแล้วเก็บไว้ในเครื่อง ไม่ผ่านบริการของที่อื่น

MinkQuickLax ไม่มีการเก็บสถิติการใช้งาน (telemetry) ไม่ส่งรายการ link หรือค่าตั้งไปที่ไหน และไม่ต้องสมัครบัญชี

## ข้อมูลในเครื่อง {#local-data}

- ค่าตั้งและรายการ link อยู่ในเครื่องนี้เท่านั้น ดู[ข้อมูลเก็บไว้ที่ไหน](#data-locations)
- log บันทึกการทำงานของ app เพื่อช่วยแก้ปัญหา มี path ของ link ที่เปิด แต่ไม่มีข้อมูลส่วนตัวอื่น และลบทิ้งเองหลัง 7 วัน
- log ไม่ถูกส่งไปที่ไหน เว้นแต่ผู้ใช้คัดลอกไป[แจ้งปัญหา](#report-problem)เอง
