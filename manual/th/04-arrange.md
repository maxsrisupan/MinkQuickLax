# จัดวางไอคอน {#arrange}

ตำแหน่งของไอคอนล็อกไว้ตอนใช้งานปกติ เพื่อไม่ให้เผลอลากไปโดยไม่ตั้งใจ จัดวางได้ 2 แบบ คือเข้าโหมดแก้ไข หรือกด Ctrl ค้างแล้วลาก

## โหมดแก้ไข {#edit-mode}

เข้าได้จากคลิกขวาที่ไอคอนหรือโฟลเดอร์ → **จัดวางไอคอน** หรือเมนูที่ tray → **จัดวางไอคอน**

ในโหมดแก้ไข

- ไอคอนทุกตัวแสดงว่ากำลังแก้ไข (Glass สั่นเบา ๆ · HUD มีวงเล็บสีเหลืองอำพันกะพริบ · Dot Matrix มีวงจุดหมุน) และชื่อใต้ไอคอนซ่อนไว้
- กดไอคอนไม่เปิด link แต่เป็นการเลือกไอคอนนั้น (ยังคลิกโฟลเดอร์เพื่อกางแผงได้)
- ด้านบนของจอมีแถบเครื่องมือ

| ปุ่มในแถบเครื่องมือ | ทำอะไร |
|---|---|
| เพิ่ม | เปิดหน้า[สแกนหา app](#scan-apps) |
| จัดเรียงใหม่ | [เรียงทุกชิ้น](#tidy)ชิดมุมขวาบนของจอหลัก |
| ยกเลิก | คืนทุกอย่างกลับเป็นเหมือนก่อนเข้าโหมดแก้ไข แล้วออก |
| เสร็จ | เก็บสิ่งที่เปลี่ยนแล้วออก |

## ลากเพื่อย้าย {#drag}

ลากไอคอนหรือโฟลเดอร์ไปวางที่ว่างบนจอ

- ตำแหน่งจะชิดกริด (ค่าเริ่มต้น 24 px) หรือชิดแนวของไอคอนอื่นเมื่อห่างไม่เกิน 8 px มีเส้นประช่วยจัดแนวให้เห็น
- ระหว่างลากมีป้ายบอกพิกัดข้างเมาส์
- ไอคอนวางทับกันไม่ได้ ถ้าปล่อยทับไอคอนอื่น ไอคอนจะขยับไปช่องว่างที่ใกล้ที่สุด
- ค่าเริ่มต้นวางทับ taskbar ไม่ได้ เปิดได้ที่[วางทับ taskbar ได้](#settings-allow-over-taskbar)

ลากไปปล่อยบนโฟลเดอร์เพื่อ[ใส่เข้ากลุ่ม](#group-members) หรือค้างบนไอคอนเดี่ยวอีกตัวเพื่อ[สร้างกลุ่ม](#create-group) · ปรับการชิดได้ที่หมวด[ตำแหน่ง](#settings-position)

## แป้นพิมพ์ในโหมดแก้ไข {#edit-keys}

กดไอคอนเพื่อเลือกก่อน แล้วใช้

| คีย์ | ทำอะไร |
|---|---|
| ← → ↑ ↓ | ขยับทีละช่องกริด |
| Shift + ลูกศร | ขยับทีละ 1 px |
| Delete | เอาไอคอนที่เลือกออกจากจอ |
| Ctrl+Z | ย้อนกลับ |
| Ctrl+Y หรือ Ctrl+Shift+Z | ทำซ้ำ |
| Enter | เสร็จ |

## Ctrl+ลาก {#ctrl-drag}

ไม่ต้องเข้าโหมดแก้ไข: กด Ctrl ค้างไว้ แล้วลากไอคอนหรือโฟลเดอร์ไปที่ใหม่ได้ทันที การชิดกริด เส้นช่วยจัดแนว และการรวมกลุ่มทำงานเหมือนในโหมดแก้ไข

ปิดได้ที่[Ctrl+ลากเพื่อย้าย](#settings-ctrl-drag) ถ้า Ctrl+ลากชนกับการใช้งานอื่น

## จัดเรียงใหม่ {#tidy}

เรียงไอคอนและโฟลเดอร์ทั้งหมดเป็นตารางชิดมุมขวาบนของจอหลัก ตามลำดับที่เพิ่มเข้ามา ใช้เมื่อไอคอนกระจัดกระจายหรือหาไม่เจอ

สั่งได้จากเมนูที่ tray, แถบเครื่องมือในโหมดแก้ไข หรือหน้าตั้งค่าหมวด[ตำแหน่ง](#settings-tidy)

## ใช้หลายจอ {#multiple-screens}

- ลากไอคอนข้ามจอได้ รวมถึงจอที่ตั้ง scale ไม่เท่ากัน
- ตำแหน่งจำเป็นสัดส่วนของพื้นที่จอนั้น เปลี่ยนความละเอียดหรือ scale แล้วไอคอนยังอยู่ตำแหน่งเดิมเมื่อเทียบกับจอ
- **ถอดจอที่มีไอคอนอยู่:** ไอคอนย้ายมาแสดงที่จอหลักชั่วคราว เสียบจอกลับแล้วกลับไปที่เดิม ถ้าย้ายเองระหว่างนั้น ตำแหน่งใหม่จะถูกบันทึกแทน
