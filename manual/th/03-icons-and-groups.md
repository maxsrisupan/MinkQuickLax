# ไอคอนและกลุ่ม {#icons-and-groups}

ไอคอนแต่ละตัวลอยอยู่บนสุดของจอ แยกกันวางได้ทุกที่ ส่วนกลุ่มคือโฟลเดอร์ที่รวมหลาย link ไว้ในไอคอนเดียว

## ใช้ไอคอน {#using-icons}

- **เปิด:** คลิกหนึ่งครั้ง (เปลี่ยนเป็น[ดับเบิลคลิก](#settings-launch-on)ได้) ไอคอนจะเด้งหนึ่งครั้งเป็นสัญญาณว่าเปิดแล้ว
- **กดพลาด:** กดค้างแล้วลากเมาส์ออกนอกไอคอนก่อนปล่อย จะไม่เปิด
- **ดูชื่อ:** ชี้ค้างไว้ครู่หนึ่ง ชื่อจะขึ้น หรือเปิด[แสดงชื่อใต้ไอคอน](#settings-show-labels)ไว้ตลอด
- **ตอนไม่ได้ใช้:** ไอคอนจางลงเพื่อไม่บังงาน เมื่อเมาส์เข้าใกล้จะชัดขึ้นและขยายเล็กน้อย ปรับได้ที่[หน้าตา](#settings-appearance)
- **ย้าย:** กด Ctrl ค้างแล้วลากไอคอน ([Ctrl+ลาก](#ctrl-drag)) หรือเข้า[โหมดแก้ไข](#edit-mode)

ไอคอนไม่แย่ง focus ถ้ากำลังพิมพ์งานอยู่แล้วกดไอคอน หน้าต่างเดิมยังรับการพิมพ์ต่อได้

## เมนูคลิกขวา {#icon-menu}

คลิกขวาที่ไอคอนเพื่อดูคำสั่งของ link นั้น

| คำสั่ง | ทำอะไร |
|---|---|
| เปิด | เปิด link |
| เปิดในฐานะผู้ดูแลระบบ | เปิดโปรแกรมด้วยสิทธิ์ผู้ดูแลระบบ Windows จะถาม UAC ก่อน (เฉพาะโปรแกรม) |
| เปิดตำแหน่งที่เก็บ | เปิดโฟลเดอร์ที่เก็บโปรแกรม ไฟล์ หรือโฟลเดอร์นั้นใน File Explorer |
| วางเพิ่มบนจอ | วางไอคอนของ link เดิมเพิ่มอีกตัวไว้ข้าง ๆ |
| เพิ่มเข้ากลุ่ม… | เลือกกลุ่มที่มีอยู่ หรือ **กลุ่มใหม่** เพื่อสร้างกลุ่มไว้ข้างไอคอนนี้ |
| แก้ไข… | เปิดหน้าตั้งค่าที่ link นี้ |
| จัดวางไอคอน | เข้าโหมดแก้ไข |
| เอาออกจากจอ | ลบแค่ไอคอนตัวนี้ link ยังอยู่ |
| ลบ link… | ลบ link ออกจากทุกที่ (ถามยืนยันก่อน) |

ถ้าอยากให้โปรแกรมเปิดด้วยสิทธิ์ผู้ดูแลระบบทุกครั้ง เปิด **เปิดในฐานะผู้ดูแลระบบทุกครั้ง** ในหน้าแก้ link ตัว MinkQuickLax เองไม่ได้ทำงานด้วยสิทธิ์ผู้ดูแลระบบ

## ไอคอนที่เป้าหมายหาย {#missing-target}

ถ้าโปรแกรมถูกถอนการติดตั้ง ไฟล์ถูกลบหรือย้าย หรือไดรฟ์ที่เก็บไฟล์ถูกถอดออก ไอคอนยังอยู่ที่เดิม แต่จะจางลงและมีเครื่องหมาย **!** ที่มุม

กดไอคอนนั้นแล้วจะมีกล่องแจ้งว่าไม่พบ พร้อมปุ่ม

- **ปิด:** ไม่ทำอะไร (เช่นรอเสียบไดรฟ์กลับ แล้วไอคอนจะกลับมาเป็นปกติเมื่อชี้ที่ไอคอนอีกครั้ง)
- **แก้ไข:** เปิดหน้าแก้ link เพื่อเลือกเป้าหมายใหม่
- **ลบ link…:** ลบ link นี้

## กลุ่ม {#groups}

กลุ่มแสดงเป็นโฟลเดอร์ขนาดเท่าไอคอนเดี่ยว ข้างในเป็นไอคอนย่อของ 4 link แรก

### เปิดกลุ่ม {#open-group}

- คลิกที่โฟลเดอร์ แผงของกลุ่มจะกางออกไปทางที่มีที่ว่างบนจอ
- ในแผงมีชื่อกลุ่มด้านบนและชื่อ link ใต้ไอคอน
- คลิก link ในแผงเพื่อเปิด แผงจะหุบเอง
- แผงหุบเมื่อกด Esc หรือคลิกที่อื่น
- คลิกขวาที่ link ในแผงเพื่อ เปิด, เอาออกจากกลุ่ม, แก้ไข หรือลบ link

### สร้างกลุ่ม {#create-group}

มี 3 วิธี

1. คลิกขวาที่ไอคอน → **เพิ่มเข้ากลุ่ม…** → **กลุ่มใหม่**
2. ลากไอคอนเดี่ยวไปค้างบนไอคอนเดี่ยวอีกตัวประมาณครึ่งวินาที จนไอคอนเป้าหมายขยายขึ้น แล้วปล่อย ทั้งสองจะรวมเป็นกลุ่มใหม่ตรงที่ไอคอนเป้าหมายอยู่
3. หน้าตั้งค่า → กลุ่ม → **กลุ่มใหม่**

กลุ่มใหม่ชื่อ "กลุ่มใหม่" เปลี่ยนชื่อได้ในหน้าตั้งค่าหมวด[กลุ่ม](#settings-groups)

### ใส่และเอา link ออกจากกลุ่ม {#group-members}

- **ใส่:** ลากไอคอนเดี่ยวไปปล่อยบนโฟลเดอร์ (ไอคอนเดี่ยวนั้นจะหายไปรวมอยู่ในกลุ่ม) หรือคลิกขวา → **เพิ่มเข้ากลุ่ม…** (ไอคอนเดี่ยวยังอยู่)
- **เอาออก:** เปิดแผงแล้วลาก link ออกนอกแผง จะกลายเป็นไอคอนเดี่ยวตรงที่ปล่อย หรือคลิกขวาที่ link ในแผง → **เอาออกจากกลุ่ม**
- **เรียงลำดับ:** ลาก link ในแผงไปตำแหน่งอื่นในแผง หรือใช้ปุ่มเลื่อนขึ้น/ลงในหน้าตั้งค่า

link หนึ่งตัวอยู่ได้หลายกลุ่ม แต่อยู่ในกลุ่มเดียวกันได้ครั้งเดียว

### ลบกลุ่ม {#delete-group}

คลิกขวาที่โฟลเดอร์ → **ลบกลุ่ม…** link ที่อยู่ในกลุ่มจะไม่ถูกลบ ยังอยู่ในรายการของหน้าตั้งค่า

**เอาออกจากจอ** ในเมนูเดียวกันจะลบแค่โฟลเดอร์บนจอ กลุ่มยังอยู่ในหน้าตั้งค่าและวางกลับได้

กลุ่มที่ไม่มี link เหลือยังอยู่บนจอเป็นโฟลเดอร์เปล่า

## สไตล์ Glass, HUD และ Dot Matrix {#styles}

เลือกสไตล์ได้ที่หน้าตั้งค่า → หน้าตา → [สไตล์](#settings-style) เปลี่ยนแล้วไอคอน เมนู แผงกลุ่ม และหน้าตั้งค่าเปลี่ยนตามทันที

| สไตล์ | หน้าตา |
|---|---|
| Glass | กระจกฝ้าที่มองเห็นพื้นหลังรำไร ไอคอนมีเงา · ปรับสีและความทึบของกระจกได้ |
| HUD | จอแสดงผลสีฟ้าเรืองแสง ไอคอนเป็นโฮโลแกรมตอนพัก เมื่อเมาส์เข้าใกล้สีจริงกลับมา ชี้แล้วมีวงเล็บล็อกเป้าและป้ายข้อมูล · ใช้สีมืดเสมอ |
| Dot Matrix | ไอคอนวงกลมที่เป็นเม็ดจุดขาวดำตอนพัก จุดขยายจนเป็นภาพเต็มเมื่อเมาส์เข้าใกล้ · ชี้แล้วมีวงจุดหมุนรอบไอคอน |

ใน HUD และ Dot Matrix ชื่อที่ขึ้นเมื่อชี้จะอยู่ด้านข้างไอคอน พร้อมลำดับของไอคอนและบรรทัดบอกชนิดของ link เช่น `แอป · CHROME.EXE`
