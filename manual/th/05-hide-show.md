# ซ่อนและแสดง {#hide-show}

## ซ่อนทั้งชุดจาก tray {#hide-from-tray}

คลิกซ้ายที่ [icon ของ MinkQuickLax ที่ tray](#tray) เพื่อซ่อนไอคอนและโฟลเดอร์ทั้งหมด คลิกอีกครั้งเพื่อแสดงกลับ

- ตอนซ่อนอยู่ ชื่อของ icon ที่ tray จะบอกว่า "(ซ่อนอยู่)"
- สั่งจากเมนูคลิกขวาที่ tray → **ซ่อนไอคอน** / **แสดงไอคอน** ได้เหมือนกัน
- เปิด MinkQuickLax ใหม่ ไอคอนจะแสดงเสมอ ไม่จำว่าเคยซ่อนไว้ จะได้ไม่คิดว่าไอคอนหาย

ถ้าไม่อยากให้คลิกซ้ายซ่อนไอคอน ปิด[คลิก icon ที่ tray เพื่อซ่อน/แสดง](#settings-tray-click) แล้วคลิกซ้ายจะเปิดเมนูแทน

## คีย์ลัดและหน้าค้นหาด่วน {#hotkeys}

คีย์ลัดสำหรับซ่อน/แสดง, หน้าค้นหาด่วนที่เปิด link ด้วยการพิมพ์ชื่อ และการซ่อนเองตอนเปิด app เต็มจอ จะมาในรุ่นถัดไป
