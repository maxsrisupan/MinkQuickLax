# เพิ่ม link {#add-links}

link คือสิ่งที่ไอคอนเปิด: โปรแกรม, app จาก Start Menu หรือ Microsoft Store, ไฟล์, โฟลเดอร์ หรือเว็บ link หนึ่งตัววางเป็นไอคอนบนจอได้หลายที่ และอยู่ในกลุ่มได้หลายกลุ่ม

## สแกนหา app ในเครื่อง {#scan-apps}

เปิดได้จากเมนูที่ tray → **เพิ่มจากเครื่องนี้…** หรือปุ่ม **เพิ่ม** ในแถบเครื่องมือตอน[จัดวางไอคอน](#edit-mode) หรือปุ่ม **เพิ่มจากเครื่องนี้…** ในหน้าตั้งค่าหมวด Link

หน้านี้แสดง app ทุกตัวที่อยู่ใน All apps ของ Start Menu และ shortcut บน Desktop

- **ช่องค้นหา:** พิมพ์ส่วนหนึ่งของชื่อ app
- **กรอง:** ทั้งหมด, โปรแกรม, Store หรือ Desktop
- **ติ๊กเลือก** ได้หลายตัว แล้วกด **เพิ่มลงจอ** ทีเดียว
- **แก้ชื่อ** ได้ในช่องชื่อก่อนเพิ่ม
- app ที่มีอยู่แล้วจะขึ้นว่า "เพิ่มแล้ว"

link ที่เพิ่มจะเป็นไอคอนเดี่ยวเรียงต่อกันที่มุมขวาบนของจอหลัก

## เพิ่มไฟล์หรือโฟลเดอร์เอง {#add-manually}

ในหน้าเพิ่มจากเครื่องนี้ แถวใต้ช่องค้นหา:

- **ไฟล์…** เลือกไฟล์หรือโปรแกรม (`.exe`, `.lnk`, `.pdf`, `.xlsx` ฯลฯ)
- **โฟลเดอร์…** เลือกโฟลเดอร์
- **เว็บ…** เปิดหน้าต่าง[เพิ่มเว็บ](#add-web)

ไฟล์และโฟลเดอร์ที่เลือกจะขึ้นในรายการพร้อมติ๊กไว้ให้แล้ว กด **เพิ่มลงจอ** เพื่อวางบนจอ

## เพิ่มเว็บ {#add-web}

เปิดได้จากเมนูที่ tray → **เพิ่มเว็บ…** หรือปุ่ม **เว็บ…** ในหน้าเพิ่มจากเครื่องนี้ หรือปุ่ม **เพิ่มเว็บ…** ในหน้าตั้งค่าหมวด Link

1. **ที่อยู่เว็บ:** พิมพ์หรือวางที่อยู่ พิมพ์แค่ `youtube.com` ก็ได้ ไม่ต้องมี `https://`
2. **ชื่อ:** ขึ้นให้เองจากชื่อเว็บ พร้อม icon ของเว็บ แก้เป็นชื่อที่ต้องการได้
3. **เปิดด้วย:** เลือก [browser](#choose-browser) หรือใช้ browser หลักตามเดิม
4. กด **เพิ่มลงจอ** หรือ Enter ไอคอนจะขึ้นที่มุมขวาบนของจอหลักทันที

- ถ้าที่อยู่ใช้ไม่ได้ จะขึ้นข้อความสีแดงใต้ช่อง และยังไม่เพิ่มอะไร
- ถ้ามี link ของเว็บนี้อยู่แล้ว จะขึ้นข้อความเตือน แต่ยังเพิ่มได้ เช่น อยากได้เว็บเดียวกันที่เปิดด้วย browser อื่น

## เลือก browser ที่ใช้เปิดเว็บ {#choose-browser}

link เว็บเลือกได้ว่าจะเปิดด้วย browser ไหน เช่น Google Chrome, Microsoft Edge หรือ Firefox

- **ตอนเพิ่ม:** เลือกในช่อง **เปิดด้วย** ของหน้าต่าง[เพิ่มเว็บ](#add-web)
- **ภายหลัง:** หน้าตั้งค่า → Link → เลือก link → **เปิดด้วย**

ค่าเริ่มต้นคือ **browser หลัก** ของ Windows รายชื่อ browser มาจากรายการที่ Windows ใช้ในหน้าเลือก browser เริ่มต้น

ถ้า browser ที่เลือกถูกถอนการติดตั้งไปแล้ว link จะเปิดด้วย browser หลักแทน และหน้าแก้ link จะบอกว่าไม่พบ browser นั้น

## icon ของ link {#link-icons}

- **โปรแกรม ไฟล์ และโฟลเดอร์:** ใช้ icon ของสิ่งนั้นที่ความละเอียดสูงสุด
- **เว็บ:** ดึง icon (favicon) จากเว็บนั้นโดยตรง ไม่ผ่านบริการอื่น
- **ไม่มี icon:** แสดงตัวอักษรตัวแรกของชื่อบนพื้นสี

เปลี่ยน icon ได้ที่หน้าตั้งค่า → Link → เลือก link → **icon**

| ตัวเลือก | ผลที่ได้ |
|---|---|
| จาก app หรือเว็บ | icon ของเป้าหมาย (ค่าเริ่มต้น) |
| ไฟล์รูป | กด **เลือกรูป…** แล้วเลือกไฟล์ PNG หรือ ICO |
| ตัวอักษร | ตัวอักษรตัวแรกของชื่อบนพื้นสี |

แก้ชื่อหรือ icon ครั้งเดียว ไอคอนของ link นั้นเปลี่ยนทุกที่ที่วางไว้

## วางหลายที่ เอาออกจากจอ และลบ link {#remove-links}

- **วางเพิ่มบนจอ** (เมนูคลิกขวาที่ไอคอน): ได้ไอคอนอีกตัวของ link เดิมไว้ในช่องว่างข้าง ๆ
- **เอาออกจากจอ:** ลบแค่ไอคอนตัวนั้น link ยังอยู่ในรายการของหน้าตั้งค่า วางกลับได้ด้วยปุ่ม **วางบนจอ** ในหน้าแก้ link
- **ลบ link…:** link หายจากทุกที่ ทั้งไอคอนบนจอและในกลุ่ม app จะถามยืนยันและบอกว่าวางอยู่กี่ที่

ในหน้าตั้งค่าหมวด Link ติ๊ก **ยังไม่ได้วางไว้ที่ไหน** เพื่อดู link ที่ไม่ได้อยู่บนจอและไม่ได้อยู่ในกลุ่มใดเลย
