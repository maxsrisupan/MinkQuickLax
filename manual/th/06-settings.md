# หน้าตั้งค่า {#settings}

เปิดได้จากเมนูที่ tray → **หน้าตั้งค่า** หรือเปิด MinkQuickLax ซ้ำจาก Start Menu

- **ปรับแล้วมีผลทันที** ไม่มีปุ่มบันทึก
- **ค้นหาค่าตั้ง:** พิมพ์ในช่องด้านบนซ้าย ค้นได้ทั้งภาษาไทยและอังกฤษ เลือกผลลัพธ์แล้วหน้าตั้งค่าจะพาไปที่ค่านั้น
- **คืนค่าเริ่มต้น:** แต่ละหมวดมีปุ่มคืนค่าเริ่มต้นของหมวดนั้นด้านล่าง
- **ขั้นสูง:** ค่าที่ไม่ค่อยได้ปรับพับไว้ใต้หัวข้อ "ขั้นสูง"
- **กด F1** เพื่อเปิดคู่มือตรงหัวข้อของหมวดที่เปิดอยู่

## Link {#settings-links}

รายการ link ทั้งหมด ด้านซ้ายค้นหาด้วยชื่อ กรองตามประเภท หรือติ๊ก **ยังไม่ได้วางไว้ที่ไหน** เลือก link เพื่อแก้ไขทางขวา

| ช่อง | ใช้ทำอะไร |
|---|---|
| ชื่อ | ชื่อที่แสดงบนไอคอน เปลี่ยนแล้วเปลี่ยนทุกที่ |
| เป้าหมาย | path ของโปรแกรม ไฟล์หรือโฟลเดอร์ หรือที่อยู่เว็บ · ปุ่ม **ไฟล์…** และ **โฟลเดอร์…** ช่วยเลือก |
| argument | ข้อความที่ส่งให้โปรแกรมตอนเปิด (ไม่มีใน link เว็บ) |
| working directory | โฟลเดอร์ที่โปรแกรมเริ่มทำงาน (ไม่มีใน link เว็บ) |
| เปิดในฐานะผู้ดูแลระบบทุกครั้ง | เปิดโปรแกรมด้วยสิทธิ์ผู้ดูแลระบบทุกครั้ง Windows จะถาม UAC (เฉพาะโปรแกรม) |
| เปิดด้วย | [browser ที่ใช้เปิด](#choose-browser) (เฉพาะ link เว็บ) |
| icon | [จาก app หรือเว็บ, ไฟล์รูป หรือตัวอักษร](#link-icons) |
| วางอยู่ที่ไหน | จำนวนไอคอนบนจอและกลุ่มที่มี link นี้ |

ปุ่มด้านล่าง: **เปิด** ลองเปิด link · **วางบนจอ** วางไอคอนเพิ่ม · **ลบ link…** ลบออกจากทุกที่ · ปุ่มด้านบน: **เพิ่มเว็บ…** เปิดหน้าต่าง[เพิ่มเว็บ](#add-web) · **เพิ่มจากเครื่องนี้…** เปิดหน้า[สแกนหา app](#scan-apps)

## กลุ่ม {#settings-groups}

รายการกลุ่มอยู่ด้านซ้าย พร้อมจำนวน link ในแต่ละกลุ่ม ปุ่ม **กลุ่มใหม่** อยู่ด้านบน

| ค่าตั้ง | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| ชื่อ | กลุ่มใหม่ | ชื่อที่แสดงบนแผงของกลุ่ม |
| แบบ | โฟลเดอร์ | แบบแถบจะมาในรุ่นถัดไป |
| จำนวนคอลัมน์ | 4 | จำนวนไอคอนต่อแถวในแผง (1–12) |
| แสดงชื่อ link | เปิด | แสดงชื่อใต้ไอคอนในแผง |
| link ในกลุ่มนี้ | – | เรียงลำดับด้วยปุ่มลูกศร เอาออกด้วยปุ่ม ✕ หรือเลือก link แล้วกด **เพิ่ม link** |

ถ้ากลุ่มไม่ได้อยู่บนจอ จะมีปุ่ม **วางบนจอ** · ปุ่ม **ลบกลุ่ม…** ลบกลุ่มโดย link ข้างในยังอยู่

## หน้าตา {#settings-appearance}

### สไตล์ {#settings-style}

Glass, HUD หรือ Dot Matrix (ค่าเริ่มต้น Glass) ดูความต่างที่[สไตล์](#styles)

### ธีม {#settings-theme}

ตาม Windows, สว่าง หรือมืด (ค่าเริ่มต้น ตาม Windows) · สไตล์ HUD ใช้สีมืดเสมอ

### ขนาดไอคอน {#settings-icon-size}

32–64 px (ค่าเริ่มต้น 48 px)

### ความทึบตอนไม่ได้ใช้ {#settings-idle-opacity}

ความชัดของไอคอนตอนเมาส์อยู่ไกล 30–100% (ค่าเริ่มต้น 70%) · ตั้ง 100% ถ้าอยากให้ไอคอนชัดตลอด

### ระยะที่เริ่มชัดขึ้น {#settings-proximity-radius}

เมาส์เข้าใกล้ไอคอนแค่ไหนไอคอนจึงเริ่มชัดขึ้น 40–400 px (ค่าเริ่มต้น 130 px)

### ขยายตามเมาส์ {#settings-magnify}

ไอคอนขยายได้สูงสุด 1.16 เท่าเมื่อเมาส์เข้าใกล้ (ค่าเริ่มต้น เปิด)

### แสดงชื่อใต้ไอคอน {#settings-show-labels}

แสดงชื่อใต้ไอคอนตลอดเวลา แทนการชี้ค้างเพื่อดูชื่อ (ค่าเริ่มต้น ปิด)

### ลดภาพเคลื่อนไหว {#settings-reduce-motion}

ตาม Windows, เปิด หรือปิด (ค่าเริ่มต้น ตาม Windows) · เมื่อเปิด ไอคอนจะไม่เด้ง ไม่สั่น และไม่มีภาพเคลื่อนไหวของสไตล์ · "ตาม Windows" ดูจากค่า Animation effects ใน Settings ของ Windows

### ค่าของสไตล์ Glass {#settings-glass}

แสดงเฉพาะเมื่อเลือกสไตล์ Glass

| ค่าตั้ง | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| สีกระจก | ตามธีม | ตามธีม, Lagoon, Ember หรือ Ink |
| ความทึบของสี | 18% | 0–70% ยิ่งมากกระจกยิ่งเห็นสีชัด |
| เบลอข้างหลัง | เปิด | เบลอสิ่งที่อยู่หลังเมนูและแผง |

ถ้าปิด Transparency effects ใน Settings ของ Windows แผ่นกระจกจะเป็นกระจกฝ้าที่เห็นสีของภาพพื้นหลัง desktop แทน (ไม่เห็นหน้าต่างอื่นที่อยู่ข้างหลัง) · เปิด Transparency effects เพื่อให้เบลอสิ่งที่อยู่ข้างหลังจริง · ถ้าเปิดโหมดประหยัดแบตหรือปิด "เบลอข้างหลัง" แผ่นกระจกจะเป็นสีทึบ

## ซ่อน/แสดง {#settings-visibility}

### คลิก icon ที่ tray เพื่อซ่อน/แสดง {#settings-tray-click}

ค่าเริ่มต้น เปิด · ถ้าปิด คลิกซ้ายที่ icon จะเปิดเมนูแทน ดู[ซ่อนและแสดง](#hide-show)

## การใช้งาน {#settings-behavior}

### เปิด link ด้วย {#settings-launch-on}

คลิกเดียว หรือดับเบิลคลิก (ค่าเริ่มต้น คลิกเดียว)

### เวลาชี้ค้างก่อนชื่อขึ้น {#settings-tooltip-delay}

0–2000 ms (ค่าเริ่มต้น 350 ms) · ใช้เมื่อไม่ได้เปิดแสดงชื่อใต้ไอคอน

## ตำแหน่ง {#settings-position}

### ขนาดกริด {#settings-grid-size}

8–96 px (ค่าเริ่มต้น 24 px) · ระยะที่ไอคอนชิดเมื่อลาก และระยะที่ลูกศรขยับในโหมดแก้ไข

### การชิด {#settings-snap}

| ตัวเลือก | ผลที่ได้ |
|---|---|
| กริดและแนว (ค่าเริ่มต้น) | ชิดกริด และชิดแนวไอคอนอื่นเมื่อห่างไม่เกิน 8 px |
| กริด | ชิดกริดอย่างเดียว |
| ไม่ชิด | วางตรงที่ปล่อย |

### Ctrl+ลากเพื่อย้าย {#settings-ctrl-drag}

ค่าเริ่มต้น เปิด · ดู[Ctrl+ลาก](#ctrl-drag)

### จัดเรียงใหม่ {#settings-tidy}

เรียงไอคอนและกลุ่มทั้งหมดชิดมุมขวาบนของจอหลัก ดู[จัดเรียงใหม่](#tidy)

### คืนตำแหน่งทั้งหมด {#settings-reset-positions}

คืนค่าตั้งเรื่องตำแหน่งเป็นค่าเริ่มต้น แล้วเรียงไอคอนทั้งหมดใหม่ (ถามยืนยันก่อน)

### วางทับ taskbar ได้ {#settings-allow-over-taskbar}

อยู่ใต้ "ขั้นสูง" (ค่าเริ่มต้น ปิด) · ปกติไอคอนวางได้แค่ในพื้นที่ทำงานของจอ ไม่ทับ taskbar

## ทั่วไป {#settings-general}

### เปิดพร้อม Windows {#settings-start-with-windows}

ค่าเริ่มต้น เปิด · MinkQuickLax เปิดตอนเข้าสู่ระบบ แสดงแค่ไอคอนและ icon ที่ tray โดยไม่เปิดหน้าต่างใด

สวิตช์นี้ตรงกับรายการ Startup apps ใน Task Manager ถ้าปิดใน Task Manager หน้าตั้งค่าจะแสดงว่าปิด และ MinkQuickLax จะไม่เปิดกลับเอง

### ภาษา {#settings-language}

ตาม Windows, ไทย หรือ English · เปลี่ยนแล้วมีผลทันที "ตาม Windows" ใช้ภาษาไทยเมื่อ Windows เป็นภาษาไทย นอกนั้นใช้ภาษาอังกฤษ · ชื่อ link เป็นข้อมูลของผู้ใช้ จึงไม่ถูกแปล

### ตรวจหาอัปเดตอัตโนมัติ {#settings-check-updates}

ค่าเริ่มต้น เปิด · ดู[อัปเดต](#updates)

### ช่องทางอัปเดต {#settings-update-channel}

**ปกติ** (ค่าเริ่มต้น) รับเฉพาะเวอร์ชันที่ออกจริง · **ทดลอง** รับเวอร์ชันทดลองก่อนออกจริงด้วย อาจมีบั๊ก

## ข้อมูล {#settings-data}

ค่าตั้งและรายการ link ทั้งหมดอยู่ในโฟลเดอร์ `%AppData%\MinkQuickLax` ดูเพิ่มที่[สำรองข้อมูลและย้ายเครื่อง](#data)

### สำรองตอนนี้ {#settings-backup}

สร้างไฟล์สำรองของค่าตั้งทันที ไฟล์สำรองเก็บ 10 ชุดล่าสุด (MinkQuickLax สำรองให้เองด้วยตอนเปิด app และทุกวันที่มีการเปลี่ยนแปลง)

### กู้คืนจากไฟล์สำรอง {#settings-restore}

เลือกวันเวลาของไฟล์สำรองแล้วกด **กู้คืน…** ค่าตั้งปัจจุบันจะถูกสำรองไว้ก่อน จึงกู้กลับได้ถ้าเลือกผิด

### เปิดโฟลเดอร์ค่าตั้ง {#settings-open-folder}

เปิดโฟลเดอร์ `%AppData%\MinkQuickLax` ใน File Explorer

### คืนค่าทั้งหมด {#settings-reset-all}

ลบ link กลุ่ม และค่าตั้งทั้งหมด กลับไปเหมือนเพิ่งติดตั้ง โดยสำรองไว้ก่อน (ถามยืนยัน)

### ลบข้อมูลทั้งหมดและออก {#settings-delete-all}

ลบค่าตั้ง ไฟล์สำรอง และ icon ที่เก็บไว้ในเครื่องนี้ แล้วปิด MinkQuickLax ย้อนกลับไม่ได้ (ถามยืนยัน) · ใช้ก่อนถอนการติดตั้งถ้าไม่ต้องการเก็บข้อมูลไว้

## เกี่ยวกับ {#settings-about}

- เวอร์ชันของ MinkQuickLax
- **เปิดคู่มือ** และ **หน้า GitHub**
- **คัดลอกข้อมูลสำหรับแจ้งปัญหา:** คัดลอกเวอร์ชันของ app และ Windows, ข้อมูลจอ, DPI และ log ล่าสุด 200 บรรทัด ไว้วางในรายงานปัญหา ดู[แจ้งปัญหา](#report-problem)
- สัญญาอนุญาตของ MinkQuickLax และส่วนประกอบที่นำมาใช้ · **เปิดไฟล์สัญญาอนุญาต** เปิดโฟลเดอร์ที่เก็บไฟล์สัญญาอนุญาตของฟอนต์
