# คำถามที่พบบ่อย {#faq}

## ไอคอนทำให้เครื่องช้าไหม {#faq-performance}

ไม่ ตอนเมาส์ไม่ขยับ MinkQuickLax แทบไม่ใช้ CPU ตอนขยับเมาส์ผ่านไอคอนใช้ไม่เกินราว 3% และใช้หน่วยความจำไม่เกินราว 120 MB แม้มีไอคอน 30 ตัว ถ้าอยากลดภาพเคลื่อนไหวให้เปิด[ลดภาพเคลื่อนไหว](#settings-reduce-motion)

## กดไอคอนแล้วหน้าต่างที่พิมพ์อยู่จะหลุด focus ไหม {#faq-focus}

ไม่หลุด ไอคอน เมนู และแผงกลุ่มออกแบบให้ไม่รับ focus กดไอคอนระหว่างพิมพ์งานได้เลย ยกเว้นหน้าตั้งค่า หน้าเพิ่มจากเครื่องนี้ แถบเครื่องมือตอนจัดวาง และคู่มือ ที่ต้องรับการพิมพ์

## ต้องใช้สิทธิ์ผู้ดูแลระบบไหม {#faq-admin}

ไม่ต้อง ทั้งตอนติดตั้งและตอนใช้งาน ถ้าบาง link ต้องเปิดด้วยสิทธิ์ผู้ดูแลระบบ ให้ใช้ **เปิดในฐานะผู้ดูแลระบบ** เป็นราย link ([เมนูคลิกขวา](#icon-menu)) Windows จะถาม UAC ทุกครั้ง

## วาง link เดียวกันหลายที่ได้ไหม {#faq-same-link}

ได้ ใช้ **วางเพิ่มบนจอ** ในเมนูคลิกขวา หรือใส่ link เดียวกันไว้หลายกลุ่ม แก้ชื่อหรือ icon ครั้งเดียวเปลี่ยนทุกที่ ดู[วางหลายที่](#remove-links)

## ใช้กับหลายจอได้ไหม {#faq-screens}

ได้ วางไอคอนบนจอไหนก็ได้ และจำตำแหน่งแยกตามจอ ดู[ใช้หลายจอ](#multiple-screens)

## เปิด app ที่ต้องใส่ argument ได้ไหม {#faq-arguments}

ได้ หน้าตั้งค่า → Link → เลือก link แล้วใส่ช่อง **argument** และ **working directory** ดู[Link](#settings-links)

## เปลี่ยนภาษาของ app ได้ไหม {#faq-language}

ได้ หน้าตั้งค่า → ทั่วไป → [ภาษา](#settings-language) เปลี่ยนแล้วมีผลทันที คู่มือก็มีปุ่มสลับภาษาที่มุมขวาบน

## MinkQuickLax ฟรีจริงไหม {#faq-free}

ฟรี และเปิดเผย source code ภายใต้สัญญาอนุญาต MIT ดูรายละเอียดและส่วนประกอบที่ใช้ได้ที่หน้าตั้งค่า → [เกี่ยวกับ](#settings-about)
