# แก้ปัญหา {#troubleshooting}

## ไอคอนหายไปทั้งหมด {#icons-gone}

1. **อาจซ่อนอยู่:** ดูที่ icon ของ MinkQuickLax ที่ tray ถ้าชื่อบอกว่า "(ซ่อนอยู่)" ให้คลิกซ้ายหนึ่งครั้ง หรือคลิกขวา → **แสดงไอคอน**
2. **MinkQuickLax อาจไม่ได้เปิดอยู่:** ถ้าไม่มี icon ที่ tray (ดูในลูกศร ^ ด้วย) ให้เปิด MinkQuickLax จาก Start Menu
3. **ไอคอนอาจอยู่นอกจอ** เช่นหลังถอดจอหรือเปลี่ยนความละเอียด: คลิกขวาที่ tray → **จัดเรียงใหม่** เพื่อเรียงทุกชิ้นไว้มุมขวาบนของจอหลัก
4. **ความทึบต่ำเกินไป:** ดู[ความทึบตอนไม่ได้ใช้](#settings-idle-opacity)

## ไอคอนบางตัวจางและมีเครื่องหมาย ! {#icon-faded}

เป้าหมายของ link หาไม่เจอ ดู[ไอคอนที่เป้าหมายหาย](#missing-target)

## ไอคอนโดนหน้าต่างอื่นบัง {#icons-covered}

ไอคอนอยู่บนสุดของจอเสมอ ถ้ามีหน้าต่างอื่นที่ตั้งให้อยู่บนสุดเหมือนกันมาบัง ไอคอนจะกลับขึ้นมาบนสุดเมื่อสลับไปหน้าต่างอื่น

- ถ้าไอคอนบังส่วนที่ใช้งานบ่อย ให้[ย้ายไอคอน](#ctrl-drag)ไปที่อื่น หรือ[ซ่อนทั้งชุด](#hide-from-tray)ชั่วคราว
- ตอนเล่นเกมหรือดูวิดีโอเต็มจอ ให้ซ่อนไอคอนจาก tray (การซ่อนเองตอนเต็มจอจะมาในรุ่นถัดไป)

## กดไอคอนแล้วไม่เปิด {#does-not-open}

- **มีกล่องแจ้งว่าไม่พบ:** ดู[ไอคอนที่เป้าหมายหาย](#missing-target)
- **ตั้งให้เปิดด้วยดับเบิลคลิกไว้:** ดู[เปิด link ด้วย](#settings-launch-on)
- **กดแล้วลากเมาส์ออก:** ถ้ากดค้างแล้วเลื่อนเมาส์ออกนอกไอคอนก่อนปล่อย จะถือว่ายกเลิก
- **อยู่ในโหมดแก้ไข:** ถ้ามีแถบเครื่องมือ "กำลังจัดวางไอคอน" ด้านบนจอ กดไอคอนจะเป็นการเลือก ให้กด **เสร็จ** ก่อน
- **กดยกเลิกในหน้าต่าง UAC:** link ที่เปิดในฐานะผู้ดูแลระบบจะไม่เปิดถ้ากด No

## ไม่เปิดพร้อม Windows {#not-starting}

1. หน้าตั้งค่า → ทั่วไป → ดูว่าเปิด[เปิดพร้อม Windows](#settings-start-with-windows)ไว้
2. ถ้าสวิตช์บอกว่าถูกปิดไว้ใน Task Manager ให้เปิดสวิตช์ในหน้าตั้งค่า หรือเปิดใน Task Manager → Startup apps → MinkQuickLax → Enable
3. MinkQuickLax เปิดตอน **เข้าสู่ระบบ** ไม่ใช่ตอนบูตเครื่อง ถ้าเครื่องค้างที่หน้า sign in ไอคอนจะยังไม่ขึ้น

## ค่าตั้งหายหรือเสียหาย {#restore-settings}

ถ้าไฟล์ค่าตั้งเสียหาย (เช่นไฟดับตอนบันทึก) MinkQuickLax จะกู้คืนจากไฟล์สำรองล่าสุดที่อ่านได้ให้เอง แล้วแจ้งว่ากู้จากไฟล์ของวันเวลาไหน ถ้าอ่านไฟล์สำรองไม่ได้เลยจะเริ่มใหม่ และเก็บไฟล์เดิมไว้ในโฟลเดอร์ค่าตั้ง

ถ้าต้องการย้อนกลับไปใช้ค่าตั้งของวันก่อน ใช้[กู้คืนจากไฟล์สำรอง](#settings-restore)

## หน้าตั้งค่าหรือคู่มือไม่ขึ้น {#window-not-showing}

- หน้าตั้งค่าอาจเปิดอยู่แล้วแต่ย่อไว้: ดูที่ taskbar หรือเปิด MinkQuickLax ซ้ำจาก Start Menu เพื่อเรียกขึ้นมา
- คู่มือใช้ Microsoft Edge WebView2 Runtime ที่มากับ Windows 11 ถ้าเครื่องไม่มี คู่มือจะเปิดใน browser แทน (แต่ไปตรงหัวข้อไม่ได้)

## แจ้งปัญหา {#report-problem}

1. หน้าตั้งค่า → เกี่ยวกับ → **คัดลอกข้อมูลสำหรับแจ้งปัญหา**
2. เปิดหน้า GitHub ของ MinkQuickLax (ปุ่ม **หน้า GitHub**) แล้วไปที่ Issues
3. เล่าว่าทำอะไรแล้วเกิดอะไรขึ้น แล้ววางข้อมูลที่คัดลอกไว้

ข้อมูลที่คัดลอกมีเวอร์ชันของ app และ Windows ข้อมูลจอ และ log ล่าสุด log อาจมี path ของ link บางตัว ตรวจดูก่อนวางถ้ามีข้อมูลที่ไม่อยากเปิดเผย
