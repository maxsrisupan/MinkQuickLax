# เริ่มต้นใช้งาน {#getting-started}

MinkQuickLax คือ quick launcher สำหรับ Windows ที่ทำให้ app ไฟล์ โฟลเดอร์ และเว็บที่ใช้บ่อยเป็นไอคอนลอยอยู่บนสุดของจอ วางไว้ตรงไหนก็ได้ กดครั้งเดียวเพื่อเปิด และรวมหลายตัวเป็นกลุ่มได้

- ไอคอนไม่แย่ง focus: กดไอคอนระหว่างพิมพ์งาน หน้าต่างที่พิมพ์อยู่ยังรับการพิมพ์ต่อได้
- ไม่โผล่ใน taskbar และ Alt+Tab
- ใช้งานได้ทั้งภาษาไทยและอังกฤษ
- ฟรีและเปิดเผย source code (สัญญาอนุญาต MIT)

## ติดตั้ง {#install}

1. ดาวน์โหลดไฟล์ `MinkQuickLax-win-Setup.exe` จากหน้า Releases ของ MinkQuickLax บน GitHub
2. ดับเบิลคลิกไฟล์ที่ดาวน์โหลดมา
3. ติดตั้งเสร็จแล้ว MinkQuickLax เปิดขึ้นมาเองทันที

การติดตั้งเป็นแบบรายผู้ใช้ จึงไม่มีหน้าต่างขอสิทธิ์ผู้ดูแลระบบ (UAC) และไม่ต้องติดตั้ง .NET แยก shortcut ของ app อยู่ใน Start Menu

## ถ้าเจอหน้าเตือน SmartScreen {#smartscreen}

ตอนเปิดตัวติดตั้งครั้งแรก Windows อาจขึ้นหน้าสีน้ำเงิน "Windows protected your PC" เพราะ MinkQuickLax ยังเป็นโปรแกรมใหม่ที่มีคนดาวน์โหลดไม่มาก ไม่ได้แปลว่าไฟล์มีไวรัส

1. กด **More info** (ข้อมูลเพิ่มเติม)
2. ตรวจว่าชื่อโปรแกรมเป็น `MinkQuickLax-win-Setup.exe`
3. กด **Run anyway** (เรียกใช้ต่อไป)

> ดาวน์โหลดตัวติดตั้งจากหน้า Releases ของ MinkQuickLax บน GitHub เท่านั้น ไม่ควรกดข้ามหน้าเตือนนี้กับไฟล์ที่ได้มาจากที่อื่น

## เปิดครั้งแรก {#first-run}

ถ้ายังไม่มี link เลย MinkQuickLax จะเปิดหน้า **เพิ่มจากเครื่องนี้** ให้ทันที

1. ติ๊ก app ที่ใช้บ่อย (ค้นหาชื่อได้จากช่องด้านบน)
2. กด **เพิ่มลงจอ**
3. ไอคอนจะเรียงอยู่ที่มุมขวาบนของจอหลัก แล้วค่อย[ย้ายไปวางที่อื่น](#edit-mode)ทีหลัง

MinkQuickLax ลงทะเบียน[เปิดพร้อม Windows](#settings-start-with-windows)ให้เองตอนเปิดครั้งแรก ปิดได้ในหน้าตั้งค่า

## icon ที่ tray {#tray}

icon ของ MinkQuickLax อยู่ที่มุมขวาล่างของ taskbar (ถ้าไม่เห็น ให้กดลูกศร ^ เพื่อดู icon ที่ซ่อนอยู่)

- **คลิกซ้าย:** [ซ่อนหรือแสดงไอคอนทั้งหมด](#hide-from-tray)
- **คลิกขวา:** เปิดเมนู

| คำสั่งในเมนู | ทำอะไร |
|---|---|
| เพิ่มจากเครื่องนี้… | เปิดหน้า[สแกนหา app](#scan-apps) |
| จัดวางไอคอน | เข้า[โหมดแก้ไข](#edit-mode) |
| จัดเรียงใหม่ | [เรียงไอคอนทั้งหมด](#tidy)ชิดมุมขวาบนของจอหลัก |
| ซ่อนไอคอน / แสดงไอคอน | ซ่อนหรือแสดงทั้งชุด |
| หน้าตั้งค่า | เปิด[หน้าตั้งค่า](#settings) |
| คู่มือ | เปิดคู่มือนี้ |
| ตรวจหาอัปเดต | ดู[การอัปเดต](#updates) |
| ออก | ปิด MinkQuickLax (ไอคอนทั้งหมดหายไปจนกว่าจะเปิดใหม่) |

ถ้าเปิด MinkQuickLax ซ้ำตอนที่เปิดอยู่แล้ว (เช่นกดจาก Start Menu) จะไม่มีตัวที่สองเปิดขึ้นมา แต่หน้าตั้งค่าของตัวที่เปิดอยู่จะขึ้นมาแทน

## อัปเดต {#updates}

MinkQuickLax ตรวจหาเวอร์ชันใหม่ตอนเปิด app และทุก 24 ชั่วโมง ถ้าเจอจะดาวน์โหลดไว้เงียบ ๆ แล้วแจ้งที่ tray ว่าจะติดตั้งตอนปิด app หรือกด **รีสตาร์ทตอนนี้** เพื่อติดตั้งทันที

- ปิดการตรวจอัตโนมัติได้ที่[ตรวจหาอัปเดตอัตโนมัติ](#settings-check-updates) ยังกด "ตรวจหาอัปเดต" จากเมนูที่ tray เองได้
- เลือกได้ว่าจะรับเวอร์ชันปกติหรือเวอร์ชันทดลองที่[ช่องทางอัปเดต](#settings-update-channel)
